# CaloTrack

Статический сайт для расчёта дневной нормы калорий и БЖУ с примерным меню на день. Работает без сборки и внешних библиотек: достаточно открыть `index.html` или раздать папку любым статическим сервером.

## Страницы

| Файл | Назначение |
| --- | --- |
| `index.html` | Главная: расчёт в виде фразы-анкеты с живой этикеткой |
| `calculator.html` | Полный расчёт: разбор формулы, прогноз веса, меню на день |
| `proteins.html`, `fats.html`, `carbs.html` | Справка по нутриентам |
| `history.html` | История расчётов и сохранённые меню |
| `about.html`, `privacy.html`, `terms.html` | О проекте и юридические тексты |

## Скрипты

- `js/theme-manager.js` — подключается в `<head>`, чтобы тема применялась до отрисовки страницы. Без сохранённого выбора следует системной теме.
- `js/common.js` — работа с `localStorage`, уведомления, разбор и форматирование дат.
- `js/nutrition.js` — расчёт нормы, разметка итога (число, полоса и таблетки Б/Ж/У) и подсказки из цифр пользователя.
- `js/mascot.js` — помощник Сырник: рисунок и облачко с подсказками.
- `js/script.js` — логика калькулятора: форма, результат, разбор расчёта, прогноз веса (SVG), сохранение в историю. Принимает параметры формы из адреса (с главной) и открывает сохранённое меню по ссылке `calculator.html?menu=<id>`.
- `js/history.js` — страница истории.
- `js/home.js` — фраза-анкета на главной: пересчёт нормы при каждом изменении.
- `js/macro-page.js` — подсказки Сырника на страницах нутриентов, включая норму из последнего расчёта.
- `js/modules/` — меню на день: база блюд (`meal-database.js`), подбор (`meal-planner.js`), отрисовка (`meal-renderer.js`) и блок меню на странице с сохранением (`meal-menu.js`). Модули общаются через события `requestMealRefresh` и `saveMenu`.

## Расчёт

1. Базовый обмен — формула Миффлина — Сан-Жеора.
2. Умножается на коэффициент активности: 1,2 / 1,375 / 1,55 / 1,725 / 1,9.
3. Цель: похудение −15 %, набор +15 %.
4. Белки и жиры считаются в граммах на килограмм веса (`MACROS_PER_KG`). Если вместе они дают больше 75 % калорий (бывает при большом весе), обе величины пропорционально уменьшаются. Остаток калорий отдаётся углеводам, поэтому сумма Б/Ж/У всегда совпадает с нормой.

## Меню

Норма делится между приёмами пищи по `caloriePercent` из `data/categories.json`. Для каждого приёма выбирается блюдо, ближайшее по калорийности, а порция масштабируется под нужные калории в пределах 70–150 %. Заметки из `healthProfiles` про размер порции не показываются, потому что порция уже подобрана расчётом.

`data/meals.json` — основная база блюд. В `meal-database.js` есть короткая встроенная копия: она используется, если JSON не загрузился (например, при открытии файла напрямую через `file://`).

## Данные пользователя

Хранятся только в `localStorage`:

- `caloHistory` — последние 20 расчётов;
- `savedMenus` — последние 10 сохранённых меню;
- `theme` — выбранная тема.
